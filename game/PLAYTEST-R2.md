## 4. 本轮（R2-02…R2-09）修复清单（均有回归证据）

1. **`tileMeshes` 索引错位**：改为与 `cells` 同索引的稠密数组 → bricksBroken 计数/负 HP 归零（r2-diag）。
2. **炮管方向**：炮管/炮口移至局部 -Z 侧，`muzzle.matrixWorld` 与 `turretForward()` dot=1.0（r2-diag）。
3. **敌人目标 Vector3 y/z 互换**：`new Vector3(...tileWorld(...),0)` 把瓦片 z 塞进 y → 敌人朝地图顶部走；改拆包构造（r2-idle/r2-base）。
4. **A* 目标格不可穿**（基地 H/钢 S）：自动改用最近可达邻格为路径终点，否则敌人原地不动（r2-base）。
5. **`hasLOS` 终点格误判遮挡**：采样点贴着目标格时把基地自身格当墙 → 贴墙敌人永不开火；起终点自身格跳过（r2-base：基地 6→0）。
6. **重装队列承诺失效**：原 swap 是 heavy↔heavy（实测 85/100 前 4 含 heavy）；改为与第一个非重装互换，200 采样 0 违例。
7. **敌人目标逻辑**：基地为主目标，玩家 <18m 且有 LOS 才切换拦截 → 基地威胁成立（n/p 组失败原因变为「基地被毁」）。
8. 相机改固定全场俯视；`.hidden` CSS 缺失导致横幅不消失；`overheatT/fireCd` 未初始化导致无法开火。

## 5. 局限（不掩盖）

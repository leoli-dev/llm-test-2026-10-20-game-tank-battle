# STEEL HORIZON — 钢铁地平线 · 3D 坦克大战（R3 固定歼灭战）

本地 Qwen3.8-27B-MLTF-q8c 独立开发、自测、自修的 3D 坦克大战。桌面浏览器直接玩。
R3 重构：保卫基地/渐进波次 → **固定歼灭战**：开局四角同时刷 4 辆敌（无补充、无波次、无基地），敌人主动追击并射击玩家；13×13 连续砖墙巷道路网迷宫（生成器固定种子，破砖=捷径）；2 条命；全灭即胜。

## 启动

```bash
cd game
npm install        # three + vite + playwright(dev)
npm run dev        # http://127.0.0.1:5179 （vite.config.js 固定端口）
```

打开 <http://127.0.0.1:5179> 即玩。生产构建：`npm run build` → `dist/`。

## 操作

| 输入 | 作用 |
|---|---|
| `W` / `S` | 地图上下 / 后退（正俯斜视角，W=画面上方） |
| `A` / `D` | 车体转向（WASD 直接控制世界方向） |
| 鼠标 | 炮塔瞄准（鼠标射线投到地面取点） |
| 鼠标左键 / 空格 | 开火（按住连发，注意炮温，过热需冷却；点射冷却随时间正常恢复） |
| `P` / `Esc` | 暂停 / 继续 |
| `M` | 静音 |
| `R`（结算面板） | 再次出击 |

## 玩法

- **目标**：歼灭全部 4 辆敌军（开局四角同时刷出、出生 2s 闪白不可被击，**无补充**）。全灭 → +500 → 任务完成。
- **失败**：2 条命耗尽（坦克损毁扣 1 命，3s 后原位复活带 3s 无敌）。
- **敌人行为（追击 AI）**：目标恒为玩家——有视线且 <22m 时接敌（<11m 横走拉扯，否则直逼）；无视线时 A* 沿巷道寻路到玩家所在格，14m 内的路径砖墙会被击穿；炮塔 2.6 rad/s 跟踪（有真实瞄准窗口）、±1.5° 散布、1.5s 冷却、24m 射程。
- **迷宫**：13×13 瓦片（1 格 = 4m > 坦克直径 2.3m）；砖墙 2HP 可被双方击毁（第二发裂纹、第三发摧毁）作**捷径**；钢墙不可破坏；外圈回廊 + 20 个回路可循环风筝；每敌初始（不穿砖）路线转角 4+、长度 13–15、岔路节点 5+。
  地图由 `tests/dev-r3-maze.mjs`（固定种子 31337，7×7 节点递归回溯 + 打通回路 + 贯通行打断）生成并固化在 `src/level.js`；结构自检见 `tests/r3-maze-check.mjs`。
- **得分**：击毁 100/辆，破砖 5，全灭奖励 500。

## 功能清单

- 3D 场景：白天战场、雾、2048 软阴影、程序化贴图（地面/砖/钢/坦克涂装/履带），钢制边界墙
- 玩家坦克：车体+可 360° 转的炮塔（炮管/炮口在局部 -Z，与 `turretForward()` 一致），固定全场俯视相机（整张 52m 战场始终可读），出生闪白、受击闪红、血条
- 敌人 AI：固定 4 辆基础型（hp24/速4.6/伤10/冷却1.8），追击/拦截/横走/A* 寻路/开砖让路/防重叠停步，出生 2s 闪白不可被击
- **R4 布局**：HUD 全部在独立顶/底栏（分数·歼灭战信息·横幅·按钮 / 装甲·炮温·生命·敌军条 N/4·小地图），中间画布独占、**任何尺寸下与 HUD 零重叠**；相机/渲染器/瞄准/投影均按实际画布区域，ResizeObserver 支持游戏中 resize；小地图默认收起（按钮切换，展开时占底栏、画布外）；窄屏保留「敌军 N/4｜击毁 n」关键数字，卡片窗口内可滚动
- 完整循环：主菜单（说明/排行榜）→ 歼灭战横幅 → 战斗 → 全灭结算（任务完成）/ 命尽结算（任务失败）→ 命名录入排行榜 → 重开/回菜单
- 音频（全部程序合成 WebAudio，用户手势解锁）：射击/命中/爆炸/受击/破砖/胜利/失败的 SFX + 合成器循环配乐
- 排行榜：localStorage 持久化 Top10（R3 独立键 `steel-horizon.leaderboard.r3`，与 R2 隔离），刷新不丢
- 测试钩子 `window.__game`（仅测试用：状态查询、冻结敌人、定点刷敌、瓦片查询/破坏、投影、扣血等）

## 已知问题 / 局限

1. **平衡未精调**：自测 bot（最近敌锁定+持续连发+逼近/横走，瞄准无误差）3/3 全胜且用时短，玩家 7m/s 对敌 4.6m/s 速度差明显；真实玩家反应/走位失误时中弹率上升（无射击观察局已验证敌人能真实打伤害）。未为通过测试调低任何敌人参数
2. 迷宫为一次性生成 + 结构指标 + 实际行走校准，未做玩家视角可玩性 A/B；中央交战口袋实战利用率不高
3. 钢墙仅 4 格且远离玩家出生，战术价值未被对局数据验证
4. 敌人转向有惯性，极窄口偶有绕行（有重选目标点自救，未观察到卡死）
5. **宽屏战场居中留白**：方战场放进横版画布，无裁切最大缩放由垂直 FOV 决定，左右留白为几何必然（详见 PLAYTEST-R4 §6）
6. 音效音量无独立滑杆（仅整体静音）；无手柄/触屏支持
7. 生产构建单 chunk ≈590KB（Three.js），未做代码分割
8. 排行榜仅本机 localStorage，无跨设备同步

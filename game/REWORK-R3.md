# REWORK-R3 — 有限歼灭战（用户试玩反馈驱动）

用户反馈三个问题（均已用现有脚本/截图确认）：
1. **敌人只轰基地不打玩家**：`r2-base` 实测玩家 hp 恒 100、敌人 goal 恒为基地格 18s；
2. **一波一波无限刷兵**：`toSpawn` 逐 4s 递减、首敌 8s 才出现（r2 日志）；
3. **砖块散点、无迷宫**：r2-shot-B / r2-play-p1 截图——孤立砖堆，无巷道/转角/迂回。

## R3 默认玩法（替换 R2 三关守基地，不保留旧刷兵）

### 1. 固定歼灭战
- 一局固定 **4 辆敌人，开局一次性全部入场**（四角），出生闪烁 2s（无敌、不可被击），随后无补充、无队列、无下一关。
- HUD 显示 `敌 N/4`。**全灭即胜利**（+500 结算）；玩家 2 条命、100 HP/命，命尽战败。
- 基地从胜负与敌人目标中移除：原基地位改为**钢墙装饰**（不可破坏、纯场景），HUD 基地条改为敌数。
- 公平开局：四角出生 + 迷宫隔离 + 2s 闪烁 + 1.5s 准备横幅；玩家出生中心。
- 排行榜换 key（`steel-horizon-board-r3`），不与旧多关分数混算。

### 2. 敌人追猎玩家（核心对象=玩家，无基地优先级）
- 目标永远=玩家位置；玩家移动换格 → 立即重寻路（A*，砖路成本 4 优先绕行）。
- 有 LOS 且距离 <20m：逼近到 ~10m 后**横走侧翼**（flank），炮塔限速 2.5rad/s 转向，
  对准窗口内开火（1.5s 冷却，±1.5° 散布——有威胁但不过度精准）。
- 无 LOS：沿路径推进；若路径必经砖且砖在 14m 内 → 对砖开火破捷径（绕行更短则绕行）。
- 弹道被墙挡（沿用 R2 子弹-瓦片碰撞）：不能隔墙命中。所有坦克遵守墙碰撞。
- 防重叠停步保留；出生 2s 内不追不射。

### 3. 砖墙迷宫（13×13，4m/格，1 格巷道=4m > 坦克直径 2.3m）
对称双环+中轴设计：外圈四角敌入口 → 环形砖廊 → 中心玩家出生；钢柱作视觉锚点；
砖墙成连续墙段（2–5 格），含 T 岔路、转角、中心可破坏捷径（玩家可 2 发打开中轴）。
连通性：validateLevel 校验玩家↔每敌入口可达（砖算可穿）；测试脚本 BFS 全图 '.'+B 连通。

```
z0 : ...............
z1 : E.BB.....BB.E     E=敌出生(0,1)(12,1)(0,11)(12,11)
z2 : ..B..SS..B...     S=钢柱(装饰)
z3 : ..B..SS..B...
z4 : ..B......B...
z5 : ..BBB.B.BBB...    → 实际 13 列: ..BBB.B.BBB..
z6 : .....P.....       P=玩家(6,6)
z7 : ..BBB.B.BBB..
z8 : ..B......B...
z9 : ..B..SS..B...
z10: ..B..SS..B...
z11: E.BB.....BB.E
z12: ...............
```
（实现时以代码内 13 字符行精确表达；砖=2HP 可破坏，钢=不可破坏。）

### 4. 保留

# REWORK-PLAN — 第二轮重构（依据用户试玩反馈）

## 用户反馈要点
1. 地图没有真正的墙体/关卡，只是散放装饰物，没有坦克大战的"打墙开路"玩法
2. 一个玩家开局被全场敌人围殴，节奏不公平
3. 只有纯色 3D 模具，没有贴图、光影，不成一个完整游戏

## 试玩取证（重构前，tests/r2-before.mjs，真实键鼠）
- 22.5s 内阵亡：3 个敌人无遮挡直扑，1 杀 27 枪；无掩体可读、无路线、材质全纯色（r2-before-play.png）
- 结论：开放场 + 全向刷兵 + 俯视不清，三者叠加造成"被群殴"体验

## 选定玩法：经典坦克大战式关卡制"守家"
- **目标（开局说明 + HUD 明确）**：保卫基地（底部 HQ）+ 消灭本关全部敌人，共 3 关。基地被毁或 3 条命耗尽 = 失败；全清 = 胜利。
- **关卡结构**：13×13 瓦片网格（每格 4m），对称设计，玩家一眼可读：
  - 玩家安全起点（底部中央，基地正下方）
  - 敌方 3 个入口（顶排 1/6/11 列）
  - 成组砖墙巷道（可破坏）、钢墙（不可破坏）、中央与两侧走廊
  - 基地（第 10 行中央）由砖墙半围护，正面留给玩家防守
- **墙体规则（核心玩法）**：
  - 砖墙：阻挡坦克与炮弹，2 发炮弹击毁（第 1 发出现裂纹贴图，第 2 发碎裂 + 碎片粒子 + 音效 + 得分），击毁后碰撞/弹道即时同步（网格单一数据源）
  - 钢墙：不可摧毁（命中火花+金属音），用于封死部分路线，但关卡保证绕行通道存在（加载时 A* 校验）
  - 玩家与敌人遵守同一套瓦片碰撞与遮挡规则（同一函数）
- **敌我节奏（反围殴）**：
  - 敌人从 3 个顶部入口**逐辆**刷出：L1 共 8 辆(最多同场 2，间隔 4s)、L2 12 辆(最多 3，3.5s)、L3 16 辆(最多 3，3s)
  - 首辆敌人延迟 4s（教学窗口）；刷出后 2s 闪烁无敌+不开火（出生保护）
  - 玩家 3 条命，复活回起点带 3s 无敌闪烁；基地 6 血，被毁即败
  - 敌人 3 种：基础(红)/快速(黄)/重装(紫)，血/速/伤害/射速递增
- **敌人 AI（不卡墙）**：网格 A* 寻路（砖=高代价可穿→会自己开砖墙，钢/基地=不可穿）到玩家(阵亡时转打基地)；炮塔有 LOS 才开火；无 LOS 时朝路径方向射击破墙开路；同向近距有他车则停步防重叠。
- **玩家决策空间**：先拆哪段墙开射线、是上前抢线还是守基地走廊、钢墙死角利用、残血时后撤/换命。

## 视角
- 弃用第三人称追尾 → **斜俯视角**（高 34m 后偏 13m 跟随相机，屏幕上方=地图北方），WASD=地图上下左右；鼠标射线投地瞄准。俯角足够大，近处墙不遮挡战场。

## 美术方案（全部程序生成 canvas 贴图，含 bump）
- 白天光照（替代过黑夜景）：半球光 1.15 + 方向阳光 1.6（2048 软阴影）、浅色雾；战场一眼可读
- 贴图：地面（泥土+网格缝）、砖墙（红砖+灰缝，两态：完整/裂纹）、钢墙（金属板+铆钉+斜纹）、基地（石座+星旗）、坦克车体（双色迷彩+划痕）、履带（重复齿纹）、炮管（金属环带）
- 尺寸/比例：瓦片 4m 高 2.2m，坦克 2.3m 宽（通道净空 1.9m），子弹/粒子/血条尺度统一
- 反馈：开火枪口闪光+曳光、砖碎粒子+残响、钢墙火花、基地被击中红闪、玩家受伤红晕、爆炸冲击环

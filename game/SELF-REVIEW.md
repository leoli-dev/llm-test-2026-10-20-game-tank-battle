## 四、本轮（R2-02…R2-11）关键修复（均有回归证据，详见 DEVLOG R2 节）

1. 炮管/炮口局部 +Z→-Z（dot=-1→1.0，r2-diag）。
2. `tileMeshes` 稀疏 push → 稠密数组（6 发 bricksBroken=114、hp=-60 → 0）。
3. 敌人目标 `Vector3(...tileWorld(...),0)` y/z 互换 → 拆包构造（敌人朝地图顶部游走 → 正确逼近基地）。
4. A* 目标格不可穿（H/S）→ 最近可达邻格代目标（敌人原地不动 → 寻路到位）。
5. `hasLOS` 终点自身格误判遮挡 → 跳过起终点格（贴墙敌人永不击基地 → 基地 6→0 实测）。
6. 重装队列 heavy↔heavy 无效互换 → 与第一个非重装互换（85/100 违例 → 200 采样 0）。
7. 敌人目标逻辑：玩家优先 → **基地主目标 + 18m/LOS 拦截**（基地威胁从名义成立变为实测成立）。
8. 相机跟随留白 → 固定全场俯视；`.hidden` CSS 缺失 → 横幅遮挡修复。
9. 测试入口：R1 波次制套件移入 `tests/legacy-r1/`（不适配，勿运行）；`npm run test:all` 改为 R2 四脚本。
